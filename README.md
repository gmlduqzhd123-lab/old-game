# 🎮 엽쌤스쿨 쉬는시간 오락실 100

> **쉬는 시간에 즐기는 추억의 미니게임 100종 · 설치 없이 브라우저에서 바로!**

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen?logo=github)](https://gmlduqzhd123-lab.github.io/old-game/)
[![PWA Ready](https://img.shields.io/badge/PWA-Ready-blue?logo=pwa)](https://gmlduqzhd123-lab.github.io/old-game/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

학교 쉬는 시간, 수업 자투리 시간, 방과 후에 선생님과 학생들이 가볍게 즐길 수 있는 **100가지 고전 미니게임 및 학급 도구 모음** 웹 애플리케이션입니다.

---

## 🌟 주요 특징

* 🚀 **설치 불필요 & PWA 지원**: 스마트폰(Android/iOS), 태블릿, PC, 스마트 전자칠판 등 모든 환경에서 링크 하나로 즉시 플레이할 수 있습니다. 홈 화면에 추가하면 앱처럼 전체 화면으로 작동합니다.
* 📶 **오프라인 플레이**: 서비스 워커(Service Worker)를 통해 한 번 방문하면 인터넷 연결이 없는 교실이나 야외에서도 플레이할 수 있습니다.
* 🎵 **자체 합성 8비트 사운드 & BGM**: 외부 음원 파일 다운로드나 저작권 걱정 없이 **Web Audio API**를 통해 실시간으로 합성되는 경쾌한 효과음과 레트로 배경 음악을 탑재했습니다.
* 🎯 **3단계 맞춤 난이도**: '쉬움(🐣)', '보통(🙂)', '어려움(🔥)' 3단계 난이도를 지원하며, 최고 기록도 난이도별로 분리 저장됩니다.
* 📱 **다양한 조작 방식**: 가상 방향키(D-Pad), 액션 버튼, 스와이프 제스처, PC 키보드 단축키를 완벽히 지원합니다.
* 💾 **로컬 자동 저장**: 기기의 브라우저 `localStorage`에 최고 점수, 칭찬 스티커판, 픽셀 아트, 사다리타기 등의 데이터가 안전하게 보관됩니다.

## 💻 로컬 실행 방법

별도의 복잡한 번들러나 빌드 도구 없이 정적 웹 서버만으로 즉시 실행할 수 있습니다.

### 방법 1. Node.js npx serve 이용
```bash
git clone https://github.com/gmlduqzhd123-lab/old-game.git
cd old-game
npx serve -l 3000
```
브라우저에서 `http://localhost:3000`으로 접속합니다.

### 방법 2. VS Code Live Server 확장
1. VS Code에서 프로젝트 폴더를 엽니다.
2. `index.html` 파일을 우클릭 후 **'Open with Live Server'**를 선택합니다.
